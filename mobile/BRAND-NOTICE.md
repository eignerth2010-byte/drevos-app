# Community artwork and brand names

`assets/logo.png` is the temporary AI-assisted wordmark designed for this
independent community project. It replaces the manufacturer's original logo
in new builds. `assets/app-icon.svg` and `assets/app-icon.png` are original
cabinet illustrations. These project assets use the current project LICENSE;
earlier MIT versions retain their original terms.
